## v1.2.0

- Добавлены сетевые голоса Edge TTS и Яндекса; в настройках можно переключаться между ними и моделями Silero. Для каждой модели сохраняется выбранный голос.
- Обновлена панель чтения: появилось управление громкостью от 0 до 200% и отключение звука.
- При сбое сетевого синтеза чтение продолжается голосом Silero.
- Установщик позволяет выбрать несколько моделей; исправлена ссылка для обновления юзерскрипта через панель SKAZ.

Откройте `README.txt` в скачанном архиве для инструкций по установке и обновлению.
