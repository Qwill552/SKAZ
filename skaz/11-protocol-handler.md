# TTS-11. `skaz://` и поведение при спящем сервере

**Цель:** сервер не запущен, человек жмёт хоткей — и вместо тишины получает уведомление
с кнопкой «Запустить», которая действительно его запускает.

---

## Отправная точка

Оба установщика закрыты (TTS-9, TTS-10) — есть куда положить регистрацию схемы. Юзерскрипт
уже умеет показывать «Сервер не отвечает» (TTS-5), но кнопки у этого сообщения нет.

---

## Разведка

**Юзерскрипт не может запустить процесс, и это принципиально.** В GM API есть сеть,
хранилище, буфер обмена, вкладки и уведомления — и ничего для запуска программ. Обойти это
изнутри Tampermonkey нельзя никак.

Правильное решение задачи — **Native Messaging**: браузер сам запускает процесс как
дочерний и убивает, когда расширение закрывает порт. Но оно требует настоящего расширения
с `nativeMessaging` в манифесте и с фиксированным ID в `allowed_origins` — то есть публикации
в сторе. Это v2, записано в решениях карты.

Остаётся **протокольный хендлер**: установщик регистрирует схему `skaz://`, страница
переходит по такой ссылке, ОС запускает программу. Так работают Zoom, Steam, JetBrains
Toolbox.

**Его ограничение надо понимать заранее.** Браузер покажет диалог «Открыть skaz?».
В нём есть галочка «всегда разрешать», но она привязана к origin — то есть **на каждом новом
сайте диалог появится заново**. У читалки сайт любой. Поэтому хендлер годится как кнопка
«запусти, пожалуйста», нажимаемая раз в день, и **не годится** как постоянный механизм.
Это стоит написать прямо в README, чтобы не выглядело недоделкой.

**Хендлер — дыра, если писать его небрежно.** Схему может дёрнуть любая страница, и строка
после `skaz://` придёт из недоверенного источника. Скрипт, который подставит её в
команду, получит удалённое выполнение кода в одну ссылку.

---

## Решение

### 1. Строгий разбор

Хендлер принимает **закрытый список команд без аргументов**:

```
skaz://start     поднять сервер, если не запущен
skaz://setup     поднять и открыть /setup
skaz://stop      погасить
```

Всё остальное — молча игнорируется. Никаких путей, портов, текста и прочих параметров из
URL. Ничего из принятой строки никогда не попадает в командную строку, в `eval`, в имя
файла. Разбор — сравнение с тремя литералами, а не парсер.

Это не паранойя, а единственный способ сделать шаг безопасным. Записать в README как
осознанное ограничение: расширять список команд можно только с таким же разбором.

### 2. Регистрация

**Windows** — ключ в `HKEY_CURRENT_USER\Software\Classes\skaz` с
`URL Protocol` и `shell\open\command`, указывающим на `handler.vbs`. Не `.bat`, чтобы не
мигало окно. Только `HKCU`, admin не нужен.

**Linux** — `.desktop` файл в `~/.local/share/applications` с `MimeType=x-scheme-handler/
skaz`, затем `update-desktop-database` и `xdg-mime default`.

**macOS** — `CFBundleURLTypes` в приложении-обёртке. Если обёртки нет, для macOS шаг можно
пропустить и записать в журнал: там автозапуск через launchd работает достаточно хорошо,
чтобы кнопка была не так нужна.

Регистрацию делает установщик, снятие — деинсталлятор. То есть TTS-9 и TTS-10 получают по
паре строк.

### 3. Сам хендлер

Крошечный скрипт. Проверяет, отвечает ли `/health` на записанном порту. Отвечает — ничего
не делает. Не отвечает — запускает сервер тем же способом, что `run.bat` / `run.sh`, и для
`setup` открывает браузер.

**На Windows используется приложение в трее из TTS-9:** хендлер передаёт ему команду,
при необходимости сначала запускает само приложение. `start` запускает сервер, `setup`
дожидается готовности и открывает `/setup`, `stop` останавливает сервер и воркер, сохраняя
значок для повторного запуска. Общий механизм управления и блокировка единственного
экземпляра исключают второй значок и второй сервер. Занятый синтезом сервер нельзя
считать остановленным только из-за задержки ответа `/health`.

На остальных ОС также исключить одновременный запуск двух копий блокировкой или
использованием штатного менеджера служб. Переход второго экземпляра на соседний порт
не считается защитой от дубликатов.

### 4. Юзерскрипт

Сообщение «сервер не отвечает» получает кнопку. По нажатию — переход на `skaz://start`
скрытым `iframe` или `location.href` (проверить, что надёжнее в Chrome; `iframe` не уводит
со страницы).

Дальше скрипт три раза с интервалом в секунду опрашивает `/health`. Ответил — молча
продолжает то, что человек просил: **сразу начинает читать**, а не просит нажать хоткей
второй раз. Не ответил — сообщение «не удалось запустить», со ссылкой на README.

Отдельный текст на случай, когда хендлер не зарегистрирован (юзерскрипт поставлен, а сервер
нет): кнопка не поможет, нужна ссылка на установку.

### 5. Чего этот шаг не делает

Native Messaging, автоматического запуска без участия человека, обхода браузерного диалога
(его нет), установки юзерскрипта из хендлера.

## Файлы

```
handler.vbs                          Windows
packaging/skaz.desktop         Linux
install.bat / install.sh             + регистрация
uninstall.bat / uninstall.sh         + снятие
userscript/skaz.user.js        кнопка в сообщении, опрос, продолжение действия
skaz.md                            статус TTS-11
```

---

## Готово когда

- При погашенном сервере хоткей даёт уведомление с кнопкой, а не просто текст.
- Кнопка поднимает сервер, и чтение начинается само, без второго нажатия.
- `skaz://` с любой другой строкой не делает ничего.
- Схема зарегистрирована установщиком и снята деинсталлятором.
- Браузерный диалог появляется один раз на сайт и запоминается галочкой.
- Работает на Linux после `update-desktop-database`.
- В командную строку хендлера не попадает ни одного символа из URL — проверяется чтением
  кода, отдельно и внимательно.

## Проверка руками

1. Погасить сервер. Хоткей на статье. Кнопка, диалог браузера, запуск, чтение началось.
2. На другом сайте — диалог появился заново (это ожидаемо, а не баг).
3. Поставить галочку «всегда разрешать» и проверить, что на этом сайте диалога больше нет.
4. Набрать в адресной строке `skaz://start%20&%20calc.exe` и подобные вариации —
   ничего не должно произойти, кроме игнорирования.
5. `skaz://setup` при работающем сервере — открывается страница, второй сервер не
   поднимается.
6. Linux: то же самое после `xdg-mime query default x-scheme-handler/skaz`.
7. Удалить схему деинсталлятором, проверить, что ссылка перестала работать.
8. Снести сервер целиком, оставив юзерскрипт, — сообщение должно вести на установку, а не
   предлагать бесполезную кнопку.

## Не трогать

Ядро чтения и сервер. Соблазн «раз уж есть хендлер, пусть он принимает текст для озвучки»
— прямая дорога к дыре; если такое понадобится, это отдельный шаг с отдельным разбором
безопасности.
