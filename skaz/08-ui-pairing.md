# TTS-8. Панель настроек и страница `/setup`

**Цель:** убрать `prompt()` и заменить его человеческим интерфейсом — панелью управления
на странице и страницей связывания на сервере. Первый шаг, сделанный не для себя, а для
тех, кто скачает релиз.

---

## Отправная точка

Работает всё ядро: TTS-6 (очередь, плеер, подсветка чанка), TTS-7 (страница целиком),
TTS-7A (пословная подсветка). Настройки хранятся в `GM_setValue`, вводятся через `prompt()`,
токен добывается глазами из консоли сервера.

---

## Разведка

**Стили сайта убьют панель.** Любой `div`, вставленный в чужую страницу, получит её CSS:
сброшенные отступы, `!important` на кнопках, шрифт в 30px, `z-index`-войну. Единственный
надёжный ответ — **Shadow DOM**: `attachShadow({mode: 'closed'})`, внутри свои стили,
снаружи ничего не протекает ни в одну сторону.

**Копипаста токена — место, где теряются пользователи.** Сейчас цепочка такая: запусти
сервер, найди консоль, найди строку, выдели, скопируй, открой меню Tampermonkey, вставь.
Шесть шагов, и на каждом кто-то отвалится. Страница `/setup` с одной кнопкой сокращает это
до двух.

---

## Решение

### 1. Панель на странице

Появляется при начале чтения, прячется через несколько секунд после конца.

**Позиция задаётся настройкой, а не перетаскиванием** — приём подсмотрен у
`Alkohole/machine-reading-text`. Выбирается угол из четырёх, смещение от него в пикселях по
обеим осям и кнопка сброса к умолчанию. Драг выброшен сознательно: он требует обработки
указателя, границ экрана, касаний и конфликтов с выделением текста на странице, а даёт то
же самое. Настройкой — двадцать строк и ноль краевых случаев.

В ней: воспроизведение/пауза, стоп, предыдущее и следующее предложение, скорость, текущее
положение («12 из 143»), индикатор буферизации, шестерёнка настроек.

Вся панель — в `closed` Shadow DOM. Стили — одной строкой внутрь теневого корня, не через
`GM_addStyle` (тот кладёт в документ, и сайт до него дотянется).

`z-index` берём высокий, но не `2147483647`: с максимумом дерутся другие расширения.
Достаточно `2147483000`.

Панель не должна перехватывать `Escape` и пробел, когда фокус на странице, — только когда
фокус внутри неё.

### 2. Настройки

Открываются шестерёнкой, живут в той же теневой панели:

Блок настроек центрируется по горизонтали относительно панели управления, между ними
зазор 8 px. Для нижних углов настройки раскрываются над панелью, для верхних — под ней.

| Настройка | Значения |
|---|---|
| Голос | пять голосов Silero, подтягиваются из `/health` |
| Скорость по умолчанию | 0.5–2.5 |
| Горячая клавиша | окно перехвата из TTS-5 |
| Подсветка предложения | вкл/выкл, цвет |
| Подсветка слова | вкл/выкл, цвет |
| Догонять прокруткой | вкл/выкл |
| Глубина префетча | 1–4, по умолчанию 2 |
| Положение панели | угол, смещение в px, кнопка сброса |
| Адрес сервера и ключ | с кнопкой «Проверить связь» |
| Словарь замен | таблица, правится прямо здесь; `+` ударение, `-` пауза |
| Обновления | текущая версия, кнопка «Проверить», ссылка на новую |

Голоса и словарь тянутся с сервера, а не хардкодятся: появится TTS-13 — список пополнится
сам. Словарь редактируется панелью и сохраняется на сервер новым эндпоинтом
`GET/PUT /dict`.

Над таблицей — пример `Цунаде → Цун+адэ` и пояснение, что слева исходное слово,
справа произношение. «Импорт JSON» открывает выбор файла в формате `user_dict.json`,
объединяет записи с таблицей и обновляет совпадающие слова. Пользователь проверяет
результат и нажимает «Сохранить словарь». Неверный файл не меняет таблицу; запоздавшее
чтение словаря с сервера не затирает несохранённые правки. Перечитывание с сервера
выполняется автоматически; отдельной неоднозначной кнопки «Загрузить» нет.

«Проверить связь» дёргает `/health` и показывает результат словами: версию сервера, бэкенд,
загружена ли модель. Это же место показывает рассогласование версий (см. TTS-12).

**«Проверить обновления»** — своя проверка, не надежда на `@updateURL`. Сравнивает версию
скрипта с последним тегом релиза и, если есть новее, даёт прямую ссылку на установку.
Автообновление Tampermonkey при этом остаётся включённым — одно другому не мешает, просто
человек перестаёт зависеть от того, когда браузер решит сходить за обновлением. Соседний
проект пришёл ровно к этому и помечает ручное обновление как рекомендуемое.

Проверка ходит **не чаще раза в сутки** и только при открытых настройках: фоновый опрос
GitHub с каждой вкладки — это лишний трафик и лишний след.

### 3. Перебор портов

Юзерскрипт при первом обращении пробует 8756…8760 с сохранённым ключом, первый ответивший
запоминает. Дальше ходит только по нему; ответ перестал приходить — перебирает заново
один раз, потом сдаётся и показывает «сервер не отвечает».

### 4. Страница `/setup`

Отдаётся самим сервером на его же порту. Открывается автоматически при первом запуске
(установщиком в TTS-9/10), дальше — по ссылке из панели.

На ней: ключ крупным моноширинным шрифтом, кнопка «Скопировать», ссылка на установку
юзерскрипта, короткая инструкция в три пункта, QR-код с ключом.

QR сейчас никому не нужен — мобильного приложения нет. Ставится он потому, что стоит
десять строк, а когда приложение появится, переделывать `/setup` не придётся.

Страница **не требует токена** — иначе её было бы не открыть. Но она отдаётся только на
`127.0.0.1` (сервер и так слушает только петлю) и только если запрос пришёл без заголовка
`Origin` или с `Origin` того же сервера. То есть открыть её чужой странице не удастся.

### 5. Связывание в один клик

На `/setup` кнопка «Связать с браузером»: по нажатию сервер на 60 секунд открывает
`GET /pair`, отдающий токен без авторизации. Юзерскрипт, увидев открытое окно, забирает
ключ сам.

Окно закрывается по первому успешному забору или по таймауту, что раньше. В логе — строка
о каждом использовании.

Это упрощение, а не обязательная часть: копипаста должна работать всегда, даже если
связывание сломается.

### 6. Чего этот шаг не делает

Мобильной вёрстки панели, тем оформления, сохранения позиции чтения между сессиями,
истории прочитанного, закладок.

## Готово когда

- Панель выглядит одинаково на пяти проверочных сайтах из TTS-7 — ни один не проломил её
  стили.
- Панель встаёт в выбранный угол с выбранным смещением; сброс возвращает умолчание.
- Положение переживает перезагрузку страницы и смену сайта.
- Все настройки применяются без перезагрузки.
- Список голосов пришёл с сервера, а не из кода скрипта.
- Словарь замен правится в панели и сразу влияет на произношение.
- Перебор портов находит сервер, поднятый на 8758.
- `/setup` открывается, ключ копируется одной кнопкой.
- «Связать с браузером» проставляет ключ без копипасты.
- «Проверить обновления» находит новый тег и даёт рабочую ссылку.
- Повторное открытие настроек в тот же день второго запроса к GitHub не делает.
- Через 61 секунду `/pair` снова закрыт.
- `prompt()` из кода **исчез полностью**.
- `Escape` на странице по-прежнему останавливает чтение, а не закрывает панель.

## Проверка руками

1. Панель на всех пяти сайтах из TTS-7, плюс на чём-нибудь заведомо агрессивном по стилям.
2. Сменить угол и смещение, перезагрузить страницу, открыть другой сайт — панель на месте.
3. Сменить голос в настройках — следующее предложение звучит новым голосом.
4. Добавить в словарь имя персонажа прямо из панели, переслушать абзац.
5. Поднять сервер на 8758 (заняв 8756 и 8757), убедиться, что скрипт его нашёл.
6. Стереть ключ в настройках, нажать «Связать с браузером» на `/setup` — ключ вернулся.
7. Подождать больше минуты после нажатия и попробовать `curl …/pair` — 401.
8. Открыть `/setup` и посмотреть в DevTools, что стили страницы не текут в панель и наоборот.
9. Проверить `Escape` при фокусе на панели и при фокусе на странице — разное поведение.

## Не трогать

Ядро чтения: очередь, чанкинг, подсветка и извлечение закрыты в TTS-6, TTS-7 и TTS-7A.
Этот шаг только даёт им интерфейс. Формат `/tts` — не меняется; новые эндпоинты `/dict`,
`/setup`, `/pair` добавляются рядом.
